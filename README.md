# Sistema-de-Pedagio  
Esse projeto simples foi desenvolvido como treinamento de Programação Orientada a Objetos.  
O sistema precisava ser composto por:  
- Classes e Objetos
- Herança
- Modularização
- Persistência em arquivo
- Métodos e atributos
- Encapsulamento simples
- Cálculos automáticos

  # Estrutura do Projeto  
  projeto_pedagio/  
  |  
  |__ veiculos.py  
  |__ pedagio.py  
  |__ salvar.py  
  |__ main.py  

  # Herança  
  - Classe Carro - Valor fixo do pedágio: R$ 12,00  
  - Classe Moto - Valor fixo do pedágio: R$ 6,00  
  - Classe Caminhao - Valor fixo do pedágio: R$ 10,00 por eixo  

    # Persistência  
    Criar um arquivo .txt em salvar.py contendo data e hora, lista de veículos e total arrecadado.  

    # Arquivo Principal(main.py)  
    Exibir o relatório com:  
    - Placa  
    - Modelo    
    - Tipo    
    - Valor Pago    
    - Total Arrecadado  
    - Quantidade de Veículos
